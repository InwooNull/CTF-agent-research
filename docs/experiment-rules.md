# 실험 규칙

세 에이전트를 공정하게 비교하기 위해 팀이 합의한 조건. 실험 중 바뀌면 날짜와 이유를 아래 변경 기록에 남긴다.

## 고정 조건

| 항목 | 값 | 비고 |
| --- | --- | --- |
| LLM | 미정 (팀 합의 후 확정) | 세 에이전트 모두 같은 모델 사용 |
| 문제당 비용 상한 | $1.00 (잠정) | EnIGMA `--per_instance_cost_limit`, D-CIPHER `max_cost`, baseline `max_cost`로 통일 |
| 문제당 반복 실행 | 3회 (잠정) | 결과 편차 대비 |
| 문제셋 | `problems.md` 참고 | 카테고리별 균형, 약 20~30문제 |
| 실행 환경 | WSL2 + Docker | 같은 PC에서 실행 |

## 기록 항목

각 실행마다 아래를 `runs/`에 요약한다.

- 에이전트, 문제, 회차, 사용 모델
- 결과: 성공 / 실패
- 풀이 시간 (시작~종료)
- 입력·출력 토큰 수, 비용
- 턴 수, 도구 호출 수
- 실패 시 실패 유형 (아래 분류)

## 실패 유형 분류

| 코드 | 유형 | 판단 기준 |
| --- | --- | --- |
| F1 | 가짜 플래그 | 근거 없이 플래그 형식만 맞춰 제출 |
| F2 | 중도 포기 | 에이전트가 스스로 종료·포기 |
| F3 | 반복·정체 | 같은 명령이나 접근을 반복하다 한도 도달 |
| F4 | 한도 초과 | 진전은 있었으나 비용·턴 한도에 걸림 |
| F5 | 환경 오류 | Docker, 네트워크, 도구 오류 등 에이전트 외부 원인 |

## 분석 범위

- 모델 내부 추론은 볼 수 없으므로, 토큰 소모의 원인 분석은 에이전트 구조(호출 횟수, 컨텍스트 전달 방식)까지만 한다.
- 구모델 결과는 직접 재실험하지 않고 논문 공개 수치를 기준선으로 쓴다.
